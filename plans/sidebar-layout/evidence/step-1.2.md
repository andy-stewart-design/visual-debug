# Step 1.2 — Minimal sidebar integration

- Implemented the WXT/Solid sidebar, synchronous toolbar-open followed by explicit start, per-window port binding, active-tab command routing, acknowledged status, Start/restart, Stop/Exit, and toolbar authorization guidance. The injected page indicator remains as the planned fallback. Reconnection/native reopening queries actual state without auto-start; sidebar Start forbids injection even if navigation removes its previously discovered receiver.
- Close coordination uses Chrome's native global-panel `sidePanel.onClosed` event (Chrome 142+, [API reference](https://developer.chrome.com/docs/extensions/reference/api/sidePanel#event-onClosed)) and Firefox port disconnect backed by window-specific `sidebarAction.isOpen` checks every 500 ms. Sidebar heartbeats/reconnection handle background connection loss without treating focus/tab changes as closure. Window shutdown invalidates pending work, stops retained sessions, sweeps untracked tabs after background restart, and serializes fresh activation after cleanup; failures are not counted as successful cleanup. These mechanisms are implemented and tested with fake native APIs, not yet proven in real browsers.
